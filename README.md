## 分類與檔名規則

- 城市資料夾以「中文 英文 韓文」依序命名，例如：`大邱 Daegu 대구`。
- 每篇文章以 Markdown（`.md`）儲存在所描述城市的資料夾。
- 檔名採「地點名稱－主要特色.md」，讓人直接辨識地點與特色。
- 同一篇來源包含多個地點時，每個地點各自建立一篇 Markdown；店家、市場與街區分開整理，不合併成一篇。僅作延伸閱讀或交通背景的地名不視為主題地點。
- 同一篇來源涵蓋多個城市時，依城市分別整理並保留來源。
- 新增前先比對既有檔案的中文、英文、韓文名稱、分店及地址；相同景點或同一分店已有檔案時不新增檔案；必須閱讀舊檔並比較新來源，將尚未收錄且有來源支持的特色補入原檔，保留原有有效資訊與所有使用者提供的出處。完全沒有新資訊才跳過。不同店家或不同分店不可只因料理或名稱相似而合併。
- 新增文章時同步更新城市索引。

## 文章整理規則

1. 以台灣用語及繁體中文摘錄重點、重新寫成生動自然的文章；可以借鏡原文的語氣、節奏與描寫方式，融入改寫，讓讀者看見地點、料理與體驗的具體魅力。
2. 說明地點特色、體驗重點與實用到訪資訊。摘要不能只剩空泛形容；優先保留可辨識店家的食材、產地或供應來源、部位、調味、藥草、器皿、前處理及烹調手法，並串聯其對風味或口感的作用。只寫來源明載的細節，不推測配方、比例或時間；韓國肉牛與韓牛等名稱不可混用。
3. 提供韓文名稱與地址；優先尋找並閱讀 Naver Search／Naver Place／Naver Map 店家頁，核對分店、道路地址、地番、電話、入口與營業公告。保留實際找到的 Naver 店家連結，不杜撰店家編號。Google 地圖僅為輔助入口，搜尋連結不能算已驗證定位。Naver 無法讀取時，須實際嘗試搜尋韓文店名及電話、查找韓文食記附帶的 Naver 連結，再用店方／地方官方與獨立韓文文章交叉核對；精確記錄哪些已核對、哪些未確認，不宣稱已讀取 Naver。
4. 原文缺少的必要資訊另行查核；無法確認時明確標示，不補造資訊。
5. 每篇新文章底部必須設置「原始文章出處」，放上使用者提供的原始文章可點擊連結；同一來源拆成多篇時，每一篇都須各自保留，不可以只放在 README 或以交叉查核來源取代。不在文章顯示整理日期或更新日期。自行搜尋且實際使用的補充文章可保留為「延伸閱讀」，與使用者提供的「原始文章出處」分開列示。
7. 不放圖片。
8. 文章必須有可閱讀的敘事，不可只有一句泛泛簡介加資訊表及大量免責套話。開頭直接呈現地點最有辨識度的特色，接續用食材、工序、吃法或空間細節串成完整段落；小標題因地制宜，不套用「到訪資訊／查核與安排提醒」等僵硬模板。實用地址及時段放在正文後，來源置底。語氣自然有溫度，善用原文已有的感官描寫與語氣感進行改寫，不必用制式的實地到訪聲明打斷閱讀。
9. 查核在整理過程完成，不把查核過程寫成文章正文。官方已列明營業時間與公休日時，直接呈現這兩項資訊，不列舊文章不同時段、不敘述工具讀取失敗，也不追加制式的未確認或出發前確認套話。只有會實際影響前往且仍無法解決的重要疑義，才簡短註明。

後續提供文章連結時，依上述規則持續新增。

- 保留自行搜尋、對內容有幫助的「延伸閱讀」，清楚標示來源；使用者提供的原始文章連結另列於文章底部。文章不顯示更新／整理日期。
