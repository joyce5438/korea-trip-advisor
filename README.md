## 分類與檔名規則

- 城市資料夾以「中文 英文 韓文」依序命名，例如：`大邱 Daegu 대구`。
- 每篇文章以 Markdown（`.md`）儲存在所描述城市的資料夾。
- 檔名採「地點名稱－主要特色.md」，讓人直接辨識地點與特色。
- 同一篇來源涵蓋多個城市時，依城市分別整理並保留來源。
- 新增文章時同步更新城市索引；相同地點優先補充既有文章，避免重複。

## 文章整理規則

1. 以台灣用語及繁體中文濃縮改寫，不整篇搬運原文。
2. 說明地點特色、體驗重點與實用到訪資訊。
3. 提供韓文名稱、韓文地址及可點擊的 Google 地圖連結。
4. 原文缺少的必要資訊另行查核；無法確認時明確標示，不補造資訊。
5. 保留原文連結及整理日期；營業時間、價格、菜單等標明來源與確認狀態。
6. 行程建議與來源事實分開，不冒稱實地到訪。
7. 不放圖片。

後續提供文章連結時，依上述規則持續新增。
